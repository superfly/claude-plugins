<h1 align="center">Superfly Plugins</h1>

<p align="center">A Claude Code plugin marketplace from <a href="https://fly.io">Fly.io</a>.</p>

## Installation

```
/plugin marketplace add superfly/claude-plugins
```

## Available Plugins

| Plugin | Description | Install |
|--------|-------------|---------|
| [sprite-handoff](./sprite-handoff) | Offload Claude Code sessions to Sprites.dev cloud sandboxes | `/plugin install sprite-handoff@superfly-plugins` |
